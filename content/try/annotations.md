This example creates Web Annotations through Diva.js's public API. Generate randomly sized and positioned rectangles, or random SVG shapes including polygons and circles, for the currently visible page, then select one from the list or directly in the viewer. The generated data is illustrative: a production integration would normally load or author annotations elsewhere.

For manifest-provided annotations, enable **Load manifest annotations** in the [Playground](/try/playground/).
